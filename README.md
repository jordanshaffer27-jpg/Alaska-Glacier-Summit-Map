# Alaska Glacier & Summit Explorer

## Project Overview

This project is an interactive web map that displays glacier and mountain summit locations throughout Alaska. The goal is to explore the geographic relationship between glaciers and nearby mountain summits using two datasets from the U.S. Board on Geographic Names.

The map was created using HTML, CSS, JavaScript, and Leaflet.

## Datasets

Two datasets were used for this project:

- **Alaska Glaciers:** Contains 643 named glacier locations across Alaska.
- **Alaska Summits:** Contains 2,000 named mountain summit locations across Alaska.

Both datasets include geographic coordinates, feature names, elevations, and other location information. The original CSV files were converted into JSON so they could be used with JavaScript.

**Data Source:** U.S. Geological Survey (USGS), Geographic Names Information System (GNIS).

## Conclusion

This project demonstrates how web mapping can be used to explore geographic patterns across Alaska. By combining two datasets and performing distance calculations, the map provides a way to examine how named glaciers and mountain summits are distributed in relation to one another.
